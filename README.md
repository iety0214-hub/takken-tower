# 宅建タワー

宅地建物取引士試験の学習アプリ。HTML1枚で動く。
正解を積み上げて夜景の街を建てていくゲームで、髙田・長谷川・佐藤・川合の4人で競う。

**公開URL**: https://iety0214-hub.github.io/takken-tower/

## 中身

| | |
|---|---|
| 収録問題 | 1,070問（オリジナル演習222／本試験17回分758／鬼レベル模試90） |
| 解説 | 全1,070問に肢ごとの解説つき |
| 法令 | 令和8年4月1日施行の法令に対応 |
| 非収録 | 問46〜50の5点免除科目 |

## 機能

- **ステージ** … 科目別10問、ライフ3
- **タイムアタック** … 60秒。自己ベスト更新でガチャ券
- **過去問** … 年度を選んで45問通し。合格ライン判定つき
- **順位表** … 8指標で4人を比較。科目別の正答率グラフつき
- **ガチャ** … 通算正解30問ごとに券。街のテーマとアイコンを解放
- **称号ランク** … 通算正解数で12段の称号が自動解放
- **きょうの一歩** … 合格予測と、その日にやる2ステップを提示

## 更新のしかた

本体は Google ドライブ側で編集する。

```
G:\マイドライブ\06_資格（宅建）\宅建タワー.html
```

編集したら、このフォルダで:

```sh
sh deploy.sh "何を変えたか"
```

Driveの本体を `index.html` にコピーして、コミットとpushまでやる。
反映は1分ほど。

## 注意

- 順位表と学習時間の共有は Supabase を使う。ネットにつながっとらんときは端末内のデータだけで動く
- 進捗は各自のブラウザにも保存される。別端末で開くと、サーバ側が進んどるほうを採用する
